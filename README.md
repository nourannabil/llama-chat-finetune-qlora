# Description :

Developed and fine-tuned a chatbot model using transformer-based architectures to deliver accurate, context-aware, and domain-specific responses.

The model was trained using supervised fine-tuning (SFT) on curated datasets, improving its ability to understand user intent and generate coherent, relevant answers.

Integrated the model into an end-to-end application with API support, enabling real-time interaction and scalable deployment.
